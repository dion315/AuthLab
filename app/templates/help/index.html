Before you start

Sign-in works on localhost; provisioning does not. An OIDC or SAML flow is carried by your browser, which can reach both ends. SCIM is a direct call from the provider's own servers to yours, so it cannot reach localhost or a private endpoint at all. To test provisioning locally, put a tunnel in front of the app and set BASE_URL to it.

This app currently believes it is at {{ base_url }}. Every redirect URI, ACS URL, and the SCIM tenant URL are derived from that, so if it is wrong, everything the guides tell you to paste is wrong too.
