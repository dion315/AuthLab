How the certificate reaches this app

TLS is terminated in front of this app on every platform it deploys to, so the client certificate arrives in a header rather than on the socket. The proxy must both request a certificate from the browser and forward it — and it must strip that header from inbound requests, or anyone could set it themselves.

Envoy and Azure Container Apps: x-forwarded-client-cert · AWS ALB: x-amzn-mtls-clientcert · nginx: whatever you set from $ssl_client_escaped_cert · Azure App Service: x-arr-clientcert

auto detects Envoy's XFCC wrapper, percent-encoded PEM, plain PEM, and bare base64 DER. Pin it only if detection guesses wrong.
